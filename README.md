# CineMax - Online Movie Ticket Booking

CineMax is a multi-page website where users can browse movies and book tickets online.

## Pages
- **Home** (index.html) - Welcome page with featured movies
- **Movies** (movies.html) - Browse all movies with a live search bar
- **Booking** (booking.html) - Book tickets for any movie
- **Details** (details.html) - View movie info, genre, director and rating
- **Contact** (contact.html) - Send a message to CineMax
- **About Us** (Aboutus.html) - Learn about the team and mission
- **Sign Up** (signup.html) - Create a new account
- **Sign In** (signin.html) - Log in to your account

## How to Open
Just open `index.html` in your browser. No server needed.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5

## Features
- Responsive navbar that collapses on mobile
- Live movie search filter on the Movies page
- Form validation on all forms (booking, contact, sign up, sign in)
- Dark / Light mode toggle that saves your preference
